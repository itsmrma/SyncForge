# Changelog

## 3.5.1 - Recursive Subfolder Destination Preservation, Red Stop Button, Descriptive Progress Pipeline & Smoothed ETA

- **Recursive Subfolder Preservation in Destination**: When selecting a folder with nested subdirectories (e.g. `Season 1/`, `Season 2/Special/`), SyncForge now preserves the identical subfolder tree in the destination output directory across all processing modules (`stream_manager`, `injection`, `custom_merge`, `internal_sync`, `sync_subs`, `sync_subs_mkv`), preventing file name collisions and flat directory dumping.
- **High-Visibility Red Stop Task Button**: Styled the Stop Task button during active pipeline execution with a vivid contained red theme (`#F43F5E`), high-contrast white text, and emergency prominence across the main application window and interactive prompt dialogs (`InputDialog`, `MatcherDialog`).
- **Descriptive Initial Progress & Pipeline Subtasks**: Replaced the ambiguous "Initializing media pipeline..." status with clear, descriptive pipeline indicators (e.g., "Analyzing file structures and dividing into groups...", "Extracting audio waveform (FFmpeg)...", "Calculating FFT cross-correlation delay (RustFFT)...", "Synchronizing subtitles to speech (FFsubsync)...", "Encoding audio stream to Opus (libopus)...", "Muxing streams into Matroska container (mkvmerge)...").
- **Real-Time Media Probing Feedback**: The progress section dynamically updates the `Current File` label to reflect the exact file being probed during initial file structure analysis and grouping.
- **Smoothed & Stable ETA Estimation**: Overhauled the remaining time calculation using an Exponential Moving Average (EMA) with step-change clamping and second-by-second countdown decrementing, eliminating upward time creep and violent fluctuations during bursty disk I/O and CPU spikes.
