# Changelog

## 3.3 - Side-by-Side Workstation, Dual-Theme Anti-Slop & mpv Sync Preview

- **Interactive `mpv` Synchronization Preview & Micro-Nudge (`SyncPreviewDialog`)**: Add an optional pre-mux verification workflow (`Preview sync with mpv before muxing` in Settings) for *Waveform Audio Sync & Merge*, *Sync Subtitle Files to Audio*, and *Extract & Sync Subs from MKV*. Launches external `mpv` (`preview_sync_mpv`) directly at the analyzed dialogue timestamp (`--start`) with real-time `--audio-delay` and `--sub-delay` flags without preliminary remuxing, and provides `+10ms`/`-10ms`/`+50ms`/`-50ms` audio nudge buttons, `+25ms`/`-25ms`/`+100ms`/`-100ms` subtitle nudge buttons, sample window recalculation (`Recalculate with different window`), and `Confirm & Mux`.
- **Side-by-Side Dockable Workstation & Active Stream Telemetry Inspector**: Upgrade the desktop workspace layout (`minmax(0, 1.55fr) minmax(300px, 1.05fr)`) so the live Developer Console can be docked directly into the right column on wide screens (`Dock Console` / `Bottom Drawer`), and replace static profile placeholders with a live **Stream & Telemetry Inspector** displaying container codec, audio/subtitle stream counts, and active task status.
- **Sub-Task CLI Transparency & Live Console Quick Action**: Parse real-time subprocess stages (`[ffmpeg]`, `[rustfft]`, `[ffsubsync]`, `[mkvextract]`, `[mkvmerge]`, `[mpv]`) into an inline activity indicator with a spinner and a one-click *"View live console"* button below Current File Progress, eliminating uncertainty during indeterminate waveform extraction and FFT correlation steps.
- **Dual-Theme Anti-Slop System (`Dark` / `Light` / `System`)**: Introduce a tri-state appearance selector in Settings supporting **Carbon-Slate Dark**, **Anodized Slate & Technical Ink Light** (`#F1F3F7` matte aluminum root, `#FAFAFC` technical paper surfaces, `#E8ECF2` recessed sockets, `#0F172A` Slate 900 ink, hairline 1px borders), and automatic OS `prefers-color-scheme` synchronization while preserving a dark `#111622`/`#070A10` CLI terminal for high-contrast log readability.
- **RAF-Batched Log Streaming, Inline Pre-Flight Validation & Accessibility Polish**: Batch high-frequency `append_terminal` stdout lines via `requestAnimationFrame`, decouple `setProgress` updates from `setTerminal`, memoize `Terminal`, `Sidebar`, and `PathInput` with `React.memo`, replace blocking empty-path error modals with inline `PathInput` validation that clears on edit, consolidate all terminal actions (`Copy`, `Download`, `Clear`, `Dock`, `Expand`, `Hide`) into the top console header bar, and add WCAG 2.1 AA `&:focus-visible` button outlines and `@media (prefers-reduced-motion: reduce)` support.
